# CatchMail Companion (Extension Chrome / Edge) 🧩

Cette extension vous permet de créer des boîtes mails instantanées et de récupérer vos codes OTP directement depuis la barre d'outils de votre navigateur !

---

## 🚀 Installation en 10 secondes :

1. Ouvrez Google Chrome ou Microsoft Edge et rendez-vous sur :  
   `chrome://extensions` (ou `edge://extensions`)
2. Activez l'interrupteur **"Mode développeur"** (en haut à droite).
3. Cliquez sur le bouton **"Charger l'extension non empaquetée"** (en haut à gauche).
4. Sélectionnez le dossier :  
   `c:\Users\Thimeo\Documents\Scripts\MyMail\extension`
5. 🎉 **C'est prêt !** L'icône CatchMail apparaît dans votre barre d'extensions.

---

## ⚡ Fonctionnalités :
- Cliquez sur **`🎲 Nouvelle Boîte Aléatoire`** : L'adresse est générée et immédiatement copiée dans votre presse-papier.
- Affiche en direct le **dernier code OTP reçu** avec un bouton de copie en un clic.
- Fonctionne en direct avec votre serveur Next.js local (`npm run dev`).
